# Gli Amici dell'Asino · nuovo sito (anteprima)

Ricostruzione statica di gliamicidellasino.wordpress.com: tutte le 25 pagine e i 36 articoli originali, con gli stessi percorsi, foto in WebP, dati strutturati (LocalBusiness, BlogPosting, FAQPage, BreadcrumbList), sitemap e llms.txt.

Anteprima: https://davide-seo.github.io/gliamicidellasino/

Le pagine portano `noindex` finché il sito resta su github.io, per non fare concorrenza al sito originale. Sul dominio definitivo si ricostruisce con `PREVIEW=0`.

Design system: https://davide-seo.github.io/gliamicidellasino/design-system/
